# Fase 0 — Base Sana Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the foundational defects (unloaded webfonts, dead Tailwind config, xl-only ToC/reader-mode, Giscus theme bug, unauthenticated upload endpoint) so the redesign phases build on solid ground.

**Architecture:** Pure fixes on the existing Next.js 16 App Router + Tailwind v4 structure. No new dependencies, no token/color changes (those are Fase 1). Fonts load via `next/font/google` and flow into Tailwind v4 utilities through an `@theme inline` block.

**Tech Stack:** Next.js 16, Tailwind CSS v4 (`@tailwindcss/postcss`), next-themes, @giscus/react, @vercel/blob.

## Global Constraints

- TypeScript strict; never introduce `any` (CLAUDE.md).
- No new runtime dependencies.
- Dark theme remains the default in this phase (`defaultTheme="dark"` unchanged); the light-default switch happens in Fase 1.
- Conventional Commits (`fix|feat|chore(scope): subject`).
- Node 22 (`seo-audit` already uses `with { type: "json" }` import attributes).
- Repo has no unit-test runner; each task verifies via `npm run type-check`, `npm run build`, `curl`, or `npm run test:e2e` as stated.
- All work happens in the current worktree; final deliverable is one PR with base `develop`.

- [ ] **Step 1: Guard the route**

In `app/api/upload/route.ts`, insert at the top of the `POST` function body (after line 4):

```ts
    const secret = process.env.UPLOAD_SECRET;
    if (!secret) {
        return NextResponse.json(
            { error: "Upload secret not configured" },
            { status: 500 }
        );
    }
    if (request.headers.get("authorization") !== `Bearer ${secret}`) {
        return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
    }
```
